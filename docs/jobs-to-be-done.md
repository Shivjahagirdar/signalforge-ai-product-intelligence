# Jobs-to-be-Done
**Core:** When I must prioritise competing investments from fragmented customer signals, help me quantify the most important opportunities so I can make defensible roadmap decisions without weeks of manual analysis.
- Functional: group duplicate/paraphrased complaints; see unique affected accounts and ACV; compare effort vs value; export a PRD.
- Emotional: feel confident defending a ranking to a VP/CFO; avoid being blindsided by a quiet high-value account.
- Organisational: align Product, CS, Eng and Finance on shared assumptions.
Alternatives today: spreadsheets, CRM exports, support dashboards, product-management suites, manual research. Switching friction: data already lives elsewhere, so CSV import is the MVP bridge.
