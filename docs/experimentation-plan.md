# Experimentation plan (protocol only - NO results exist)
**Hypothesis:** PMs using SignalForge produce a defensible roadmap recommendation faster than with spreadsheets, at equal or better rated quality.
**Design:** within-subject crossover, randomised task order; unit = PM. **Primary metric:** minutes to a recommendation scored >= 4/5 by a blinded reviewer. **Guardrails:** reviewer-rated quality, ranking stability, false-merge rate. **MDE:** 30% time reduction (assumption). **Sample:** ~20 PMs for a paired design (planning assumption, not computed power). **Analysis:** paired Wilcoxon, report effect size and CI. **Stop/go:** go if >=30% median reduction with no quality drop; stop if quality falls.
Status: not run. Participants: none recruited.
