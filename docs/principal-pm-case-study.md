# Case study: SignalForge AI (personal portfolio project)
Built independently as a portfolio project; **not** an AWS project and uses no employer or customer data.
**Insight:** the loudest request is not the most valuable. In the synthetic demo, a Salesforce-sync defect affecting 12 high-ACV accounts ranks #1 while a dark-mode request from many small accounts ranks lower; baseline severity x frequency ranks them the other way.
**Decisions:** smallest journey, explainability over automation, scenario-labelled economics, honest limits.
**Verified:** 21 automated tests pass; benchmark on synthetic data reproducible. **Unverified:** real-world clustering accuracy, willingness to pay, competitor gaps.
**Truthful resume bullet options:** (1) Built an end-to-end revenue-at-risk roadmap prioritisation prototype (Python, Streamlit, scikit-learn) with 21 automated tests. (2) Designed unique-account exposure and scenario analysis that prevent double-counting in prioritisation models. (3) Authored PRD, threat model and unit-economics hypotheses for an AI product-intelligence concept.
