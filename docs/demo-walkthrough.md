# 5-minute demo walkthrough (mirrors the automated E2E journey)

1. **Executive Dashboard** - synthetic demo loads by default (yellow SYNTHETIC badge). Read the SIGNAL banner, KPIs
   (hover ⓘ for each calculation), data quality 100/100, top 3 actions with evidence sufficiency.
2. **Customer Intelligence** - pick a theme: shared terms, representative records, contradicting evidence, affected
   accounts. Merge / split / reject / rename; undo all. Every action lands in the audit trail.
3. **Opportunity Economics** - change *Recovery probability* in the sidebar and watch every value recalculate;
   open *Formulas*; compare bear/base/bull.
4. **Roadmap Optimizer** - switch frameworks (RICE vs WSJF vs Custom), drop capacity to 5 person-weeks, add a
   dependency, override a priority with a rationale; compare optimised vs sort-and-fill and the alternative plan.
5. **Scenario Lab** - cut capacity 30%, change the seed, set a funding threshold.
6. **SIGNAL** - "Challenge this roadmap." and "What would a CFO prioritize?".
7. **Decision Memo & PRD** - download the PRD (.md) and the full decision pack (.docx).
8. Switch the dataset to **Public: F-Droid app reviews** or **GitHub issues (live)**: red NO-REVENUE badge, the same
   analysis on real text, $ only via an explicit assumption.
